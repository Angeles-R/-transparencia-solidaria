# Transparencia Solidaria

Sistema web para la gestión y transparencia
de donaciones económicas y en especie.

## Tecnologías

- React y TypeScript
- Node.js y Express
- PostgreSQL
- Rust
- Solana y Anchor

## Objetivo

Registrar donaciones, administrar inventarios,
gestionar beneficiarios y documentar entregas
de apoyos mediante evidencias verificables
en blockchain.

## Red blockchain

Solana Devnet (entorno de pruebas).

## Estado

Desarrollo de prototipo académico.
